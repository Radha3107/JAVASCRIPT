JS Concepts Used

if / else Form validation — checks empty fields, numeric range, and pass/fail status
switch Maps percentage ranges to letter grades (A+, A, B+, B, …)
for Iterates over the 5 subject mark inputs for validation & totalling
while Scans marks to count subjects scoring above 75
do…while Builds the subject breakdown rows (at least one subject always exists)
? : Ternary operator — concise pass/fail & CSS class assignment
